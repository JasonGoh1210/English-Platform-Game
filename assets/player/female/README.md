# Female adventurer sprite

- Asset: female_adventurer_sheet.png (transparent RGBA PNG, 4 columns x 2 rows).
- Generated with the built-in imagegen tool, not the CLI. Male frames and Elder Rowan are unchanged.
- Cell order: idle, six right-walk frames, unused idle. Runtime code reads native image dimensions, extracts each cell's alpha bounds, applies one shared scale, then anchors boots to y=72. Idle is 72x72; walks are 48x72; left walking mirrors right.
- Clothing palettes preserve alpha, skin and warm brown hair. No SQL migration required. Saved female gender selects this asset throughout preview, map, HUD, Story, battle and Typing Cavern.

## Generation prompt

Create a production-ready transparent PNG pixel-art sprite sheet for the female player in an existing fantasy side-scrolling English-learning RPG. New asset only. Square image 1024 x 1024, EXACT regular grid 4 columns by 2 rows, 8 equal cells (256 x 512). No grid lines, labels, numbers, background, scenery, shadows, ground or decorative effects. Each cell contains exactly ONE full-body instance of the SAME clearly female young adult adventurer. Readable feminine face, long warm chestnut hair with a loose ponytail and bangs, youthful brave gentle expression. Fully clothed modest fantasy travel outfit: fitted dark indigo tunic, split short violet cape, belt, leggings, dark boots. No weapons. Rich but restrained SNES-style crisp pixel art with black outlines and block shading, no smoothing or painterly texture. Her silhouette should read as a girl at small scale, not a recolored male. Keep identical facial identity, hairstyle, costume, proportions and scale in every cell. Pixel resolution impression about 48 x 80 pixels per character scaled nearest-neighbor. All sprites entirely within cell bounds, centered horizontally with large transparent padding; identical baseline at 470 px within each 512-high cell, highest point at approximately 120 px. Never cut off feet, hair or cape. Read cells left-to-right then top-to-bottom: cell 0 = standing idle, slight three-quarter view toward RIGHT; cells 1,2,3,4,5,6 = six consecutive frames of a smooth WALK RIGHT cycle, full lateral right-facing body, feet and arms alternating with distinct contact/down/passing/up/opposite-contact/passing poses, subtle ponytail and cape movement, same horizontal center and baseline. Cell 7 = repeat standing idle from cell 0. Faces and toes in ALL cells point toward the viewer's RIGHT. Genuine alpha transparency throughout empty areas, no baked checkerboard. Keep dark garment colors blue/violet, warm skin and brown hair separate so code can recolor clothing without changing skin or hair.

The tool returned a 1280x1280 sheet; runtime cells use the returned dimensions rather than the requested size. Final native Canvas frames and alpha/foot alignment were checked in the browser.
