# 远处城堡与最终 Boss

按用户截图要求缩短地面、扩大天空，并把古代遗迹右侧大门换成更远处的像素城堡。

## 玩家流程

- 2026-10-17 按最新反馈，电脑地图先均分，随后按最新微调改为天空约 55%、地面约 45%；短横屏及手机竖屏保留 HUD 避让，让人物头部不被操作栏遮住。
- 回声洞穴仍在 X1680。终焉城堡在 X3700，相隔 2020 世界像素；古代遗迹室外延长到 4600，玩家走过洞穴后继续向右才会看到城堡。城堡入口附近按 E／互动进入。
- 野外文法守卫的胜利仍是进入条件。回声洞穴继续使用原有幽魂及房间；其内部宽度保留 2200，不随室外道路延长。
- 原最终拼字挑战现在发生在城堡大厅，只有一只新 Boss“无言魔王”。三次服务器确认的正确拼写依次击碎三道封印，显示苏醒、暴怒、最后抵抗三个阶段；答错或等待太久仍让魔王靠近，最后两个字母始终隐藏。
- 完成凯的章节后，击碎三道封印接回原来的主线结局；失败可查看原有拼写解析、重试或退出。普通练习、每题奖励及结局的一次性奖励规则保持原样。

这是三阶段拼字 Boss 战，使用现有任务接口，不是额外新增一场普通答题战斗。商店、技能、角色和其他世界保持原流程。

## 文件与兼容

`data/world_layout.json` 与 `includes/world_layout.php` 统一室外／洞穴边界和城堡坐标。`index.php` 将配置传给地图；`api/game_state.php` 同步保存范围；`includes/quests.php` 在新城堡位置验证挑战入口。旧大门位置不再允许新开挑战。已有玩家位置、章节、库存和奖励记录不重置，旧的已开始拼字挑战仍可通过原 run ID 结算。

主要界面在 `js/rpg.js`、`js/quest-guidance.js`、`js/i18n.js`、`includes/quest_guide.php` 与 `css/dungeon-pixel.css`。通用模块及页面入口统一缓存版本 `20261015-castle1`，保留共享语言实例；加载控制器仍使用 `20261015-loading2`。
