# 像素技能路线、冒险手册与通关变化

本次按最新要求移除探索小支线，保留四世界主线、洞穴、城堡、现有角色和已获得的奖励。无需新增 SQL 或安装图片。新的视觉效果使用现有精灵、像素 SVG 和 Canvas 绘制。

## 技能树

三条路线同时显示，节点用直角路径连接，选中后在旁边查看具体效果和每项解锁条件。小屏把详情移到路线下方；方向键可以在分支和等级之间移动。颜色、图标、勾选和文字共同表示已学习、可解锁与条件不足。

沿用九项真实技能及其原有购买记录：词汇之力、语法守护、句子蓄能各三级，每级消耗1/2/3技能点，要求角色等级2/3/5。三条路线共用点数；高级效果替换同一分支的低级效果，从下一场战斗生效。服务端检查前置、等级、余额，重复请求不会再次扣点。

## 一个手册入口

右下角「冒险手册」有四个页签，原来的支线追踪与线索任务已删除。已有支线记录只作兼容保留，未完成线索不会重新打开，旧奖励不会扣回。区域地图仍可折叠。

| 页签 | 内容及依据 |
| --- | --- |
| 怪物图鉴 | 十二种当前可遇到的怪物；未遇到时显示剪影，实际遭遇后显示生命/封印与打法笔记，获胜后解锁词语卡片和胜利次数。旧村庄高塔不列入新角色收集目标。 |
| 世界进度 | 分别列出主线、外部守卫、当地正确作答、实际可用的内部守卫；遗迹还包含树妖、侍卫、城门和最终 Boss。100%可领取一次20经验、15金币徽记，不强制复习或购买外观。 |
| 学习成长 | 每道战斗题的首次提交、战斗重答、记忆复习、城堡封印分别统计；各知识类型显示真实正确数与样本量。没有数据时显示空值。至少20道不同题后，比较最初与最近各10道新题的首次表现。 |
| 随从 | 十种外观各自的同行目标、进度与专属徽饰。必须拥有并装备对应随从，且达到实际记录要求，才能领取一次10经验、5金币。徽饰只有外观效果。 |

世界完成度、徽饰和报告读取当前角色的服务端记录，不信任浏览器上报的百分比、金币或完成标记。旧学习页中未记入历史的自由练习不会凭空补算成绩；报告明确区分记忆祭坛复习和其他练习。

## 记忆与遗迹

259个现有知识点各有三份复习情境，共777份；判断题改成新场景理解选择，排句替换具体人物或物品，分类题用整理场景重考相同分类知识。后续复习也会更换部分人物、物品与地点。不是新增777道战斗题。

历史题目的原始内容发生变化时，仍按当时保存的原题复习，避免用新版答案解释旧记录。复习不扣血、不发战斗奖励。服务端控制复习间隔：成功后5分钟、1天、1周；错误后1分钟。每题连续三次成功掌握符文，首次掌握发10经验、8金币，重复提交与重新掌握不会重复发奖。

正确复习逐步修复所在世界的实际像素石柱、横梁与发光符文，最高三级。遗迹位置：枫叶镇1290、森林1450、营地1810、古代遗迹1950。新的错误会重新开启该知识点的复习，但已经修好的场景不会倒塌。

## 怪物与最终 Boss

树妖的两层藤蔓、侍卫等怪物的护盾直接绘制在怪物身上，破除后有短暂像素碎片。蝙蝠俯冲与守卫符文有可见预警；这些演出读取已确认的战斗状态，不参与评分或暗中改变伤害。

三道封印分别为词义选择、句子排列、单词拼写；对应不同动作节奏、场景粒子与原创合成8位音乐。最后一击播放像素瓦解与余烬动画，再显示结局或胜利界面。重试恢复怪物，退出会取消尚未完成的演出。浏览器声音仍需真实点击/按键开启，遵守静音、音量与页面隐藏设置；减少动态效果时停止持续摇动并改用柔和淡出。

旧的进行中战斗、旧的三轮拼写 Boss 快照仍按原规则结算；结局奖励仍只发一次。

## 随从与通关村庄

- 猫头鹰可以停栖在村庄路牌旁；狐狸在补给箱附近独立摇尾；蝙蝠在洞口附近绕飞。
- 十只随从都能回应手册中的招呼。地面随从有跳跃、点头或伸缩，飞行随从保持飞行并作出回应；原有跟随朝向与带路动作保留。
- 同行目标使用已有主线、战斗、复习和商店记录，不新增探索支线或需要寻找的任务物件。
- 首次通关后可直接回枫叶镇参加庆典：村庄出现像素彩旗、灯笼和纸屑，长老、商人及其他世界角色有新的对话。主线指引改为回村找长老；结局状态刷新后仍保留。

## 验证方式

`tests/handbook_flow_smoke.php` 在独立数据库上执行原有战斗/主线/商店/题目回归，再检查图鉴、完成要求、徽饰拥有/装备条件、隔离角色、CSRF、重复领取、学习分组与旧奖励兼容。`tests/memory_context_test.php` 验证全部777份情境、答案与排句词袋，以及旧题快照回退。

浏览器检查使用独立测试角色和测试数据库；角色等级、测试资金、固定题目和复习到期时间可由夹具调整，实际解锁、答题、领取与通关仍走正常界面或受保护接口。没有写入正式数据库。

最终结果：106项 Node 检查、9套独立 PHP 规则检查通过；777份复习情境全部通过严格答案与词袋检查。独立数据库完整回归、实际浏览器主线试玩、九项技能购买、三道封印、十只随从动作、重复领取、旧存档、静音和减少动态效果均已检查。手册和技能树检查中英文320/390/640/1280宽度，Boss 检查1280/390/640及短横屏可滚动控件，控制台无游戏错误。

画面复查修正了回村初帧偶发缺少缓存图层的问题：小型人物、随从与建筑画布保留像素缓冲，传送结束前完成绘制。最终检查实际读取首帧人物与建筑像素，并打开截图确认；测试数据库和网页服务已关闭。XAMPP 的 `C:/xampp/htdocs/FYP` 指向当前项目，刷新本地游戏即可看到修改。
