# 像素加载界面

2026-10-15：按“帮我加loading页面”加入统一加载界面，保留现有 PHP/MySQL/Canvas 和存档流程。

## 页面准备条件

| 页面 | 何时进入 |
| --- | --- |
| 登录、注册 | 表单及本页图片准备好；不等待 Google SDK |
| 创建角色 | 当前性别的角色预览及原始精灵准备好 |
| 地图 | 世界存档、玩家数据、任务恢复及必要角色／场景资源准备好 |
| 战斗 | 首屏图片与最短展示时间先完成，再发起原有 START 请求 |
| 技能树、商店、学习记录 | 首次接口请求结束并渲染结果；失败则展示页面原有重试入口 |
| 传送门 | 切换所选世界，准备其背景、野外怪物、NPC 和入口图片；至少展示 3 秒 |

按后续“传送门也要，然后可以loading久一点”的要求，普通页面最短展示时间设为 2 秒，传送门为 3 秒。时间从加载界面完成显示及焦点设置后开始计算，资源未准备好时继续等待。失败提示和返回操作不受这个展示时间限制，战斗的等待安排在 START 之前。

同站普通链接、通过验证的表单提交、地图保存后跳转和战斗返回也显示加载提示。不会拦截下载、外部链接、新窗口或带 Ctrl／Shift 等修饰键的链接，也不会替页面发起购买或重复表单提交。

## 行为与维护

- `includes/loading_screen.php` 在各 PHP 页头加载独立的 `css/loading.css` 和 `js/loading.js`，缓存版本 `20261015-loading2`；地图与战斗入口一同更新。已有共用语言模块的版本保持原样。
- 通过 `window.EPQLoading` 的 `step`、`ready`、`fail` 和 `waitForImages` 接收实际准备状态；导航使用 `begin`，战斗在 START 前使用 `waitForMinimum`。没有伪造百分比；最短展示时间只延长快速加载，图片失败保留游戏已有后备画面。
- 传送显示所选世界的本地化名称，加载期间阻止连续确认和移动。原来的四世界坐标、固定传送门、位置记忆与保存流程保留。旧的完成计时器不能关闭新的传送遮罩；选择界面隐藏后，焦点返回地图。
- 加载时阻止背后内容获得焦点，地图清空移动输入并停止更新；恢复后保留原有 inert 状态并恢复焦点。浏览器缓存返回时清除跳转遮罩。页面脚本未加载时，独立的 20 秒提示提供“重新打开”和“返回页面”。重新打开使用 GET，不重放 POST。
- 中文默认，尊重已保存的英文选择；支持减少动画偏好、窄屏和短横屏。使用已有像素传送门与村庄背景，无新增图片或数据库更新。

## 验证

89 项 Node 回归测试、66 个 PHP 文件及 30 个 JS／工具文件的语法检查通过。Chrome 使用实际 PHP 页面及独立 3307 测试数据库验证游客创建、角色预览、故事、地图恢复与移动、技能接口失败重试、商店六种随从、学习记录、战斗 START 及逃跑返回。接入加载界面后，原有完整技能浏览器回归也通过：三次持久解锁、精确扣点、回包丢失后同目标重试、过期凭证及确认框键盘操作。正式 3306 玩家库未参与测试。

故意延迟页面模块验证中英文七种尺寸（1280×900、768×1024、390×844、320×740、844×390、640×360、568×320），故意阻断模块验证真实 20 秒超时和键盘恢复；阻断 Google SDK 后普通登录表单仍可用。地图恢复延迟时按方向键或推进游戏时间均不移动，准备完成后移动恢复。战斗图片延迟时不先发 START。标准游戏 Playwright 客户端的地图截图和文本状态已检查。

传送后续实测：通过真实传送门界面依次到森林、营地、遗迹、村庄；缓存资源时分别约 3.004／3.008／3.005 秒，故意延迟森林背景时约 3.471 秒并确认图片释放前不退出加载。普通页至少 2 秒、战斗先等展示再 START、重复点击拦截、地图焦点、位置记忆及刷新、旧完成计时器取消、超时返回与缓存恢复均通过。桌面／320px 传送截图和标准客户端最终地图截图已打开检查。证据目录为 `portal-loading-browser-1792070934470` 和 `portal-loading-canonical-1792070920876`。

自动化浏览器脚本和截图在工作区外的 `loading-browser-*`、`loading-canonical-*` 测试目录中，运行器 `loading-check.cjs` 会退出它自己启动的 PHP 和临时数据库。Chrome 尺寸模拟不等同于真实手机硬件测试。修改保持本地，未提交或推送。

刷新页面按 Ctrl+F5，不需要导入 SQL。
