# 领域传送界面更新

- 中央整张地点卡片可以点击或触摸传送，标题、说明、背景和卡片角落都属于点击区域。移除卡片内的选择按钮和下方的「传送到这里」按钮，保留「返回地图」。
- 左右箭头和返回按钮使用黑白像素立体按键。按住时键面下沉、底部阴影缩短，松开后恢复；键盘切换也会显示按下反馈。系统开启减少动态效果时关闭过渡动画。
- ← / → 或 A / D 切换地点，Tab 在界面内选择控件，Enter / 空格操作当前控件；打开界面时默认聚焦地点卡片，Esc 返回地图。中英文按钮名称和使用提示同步更新。
- 四个世界的地图、传送门坐标和各世界已保存的玩家位置继续使用原有逻辑。重复激活已关闭的传送界面不会再次执行传送。

修改文件：`index.php`（界面结构）、`css/pixel-theme.css`（按钮、整卡点击层、响应布局）、`js/rpg.js`（点击和键盘）、`js/i18n.js`（中英文提示）。`battle.php`、`js/battle.js`、`js/save-status.js`、`js/story-visuals.js` 只同步资源版本，防止浏览器沿用旧模块。

资源继续使用 `images/world/pixel/{maple,forest,camp,ruins}.png`。箭头由代码绘制像素边缘，无新增图片，无数据库迁移。

验证：47 项 Node 测试、46 个 PHP 文件及所有 JavaScript 语法、六组 PHP 规则测试通过。独立 PHP 8081 / MariaDB 3307 环境验证真实传送和刷新存档、卡片多个位置的点击、键盘/触摸/返回、按钮按下效果、中英文及七种屏幕尺寸；四世界战斗、战后总结、洞穴战斗及新手移动回归通过，无浏览器页面或控制台错误。已打开实际截图检查。未访问原有 3306 玩家数据库；手机检查为 Chrome 模拟，尚未进行实体手机测试。
