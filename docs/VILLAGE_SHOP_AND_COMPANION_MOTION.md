# 村庄商店与随从动作

枫叶镇原来 X1580 的高塔改成低矮的像素木石商店。靠近后按 E／互动进入现有商店，可购买药水和六种随从。原来 X1080 的商店房屋改作普通村舍，任务与洞穴面板只列出低语森林、旧营地道路和古代遗迹的挑战。

枫叶镇仍保留原有长老、剧情、新手小怪与教学。旧高塔的定义标为 `legacyOnly`，保留已有战斗、奖励、历史和内部存档兼容；旧角色可从内部大门安全返回村庄。地图没有新的高塔入口。

随从在跟随模式朝向玩家，并跟在玩家当前朝向的后方；带路模式朝任务路线移动并看向路线。六种外观使用独立的八帧透明像素素材，前四帧待机、后四帧移动。

| 随从 | 移动方式 |
|---|---|
| 向导猫头鹰 | 悬浮、振翅飞行 |
| 枫叶小狐 | 迈步、尾巴摆动 |
| 星月灵猫 | 迈步、尾巴摆动 |
| 青晶幼龙 | 悬浮、振翅飞行 |
| 萤灯精灵 | 悬浮、鳍与尾迹变化 |
| 信使白兔 | 蹲下、蹬腿、跳起、落地 |

素材逐帧裁切后缓存，关闭平滑缩放；共用帧锚点避免跟随翅膀边界重新定位身体。飞行随从位于地面上方，并带有清晰的像素落影；地面随从的脚步锚点对齐行走平面。加载期间仍能使用原图。

实现文件：`js/rpg.js`、`js/companions.js`、`js/i18n.js`、`data/shop.json`、`data/dungeons.json`。所有原商品 ID、价格、库存和购买记录保留，无需数据库迁移。PHP／JavaScript 共享缓存版本更新为 `20261015-village2`。

竖屏行走平面按顶部状态栏高度下移，为商店和人物保留场景空间；小横屏收起商店的悬浮文字，保留商店和 E／互动操作，避免文字挡住人物。只改变屏幕中的绘制位置，玩家世界坐标和保存格式不变。

新素材位于 `images/shop/village-apothecary-192.png` 与 `images/companions/{owl,fox,cat,dragon,wisp,bunny}-motion-64.png`。它们由内置 image_gen 生成，再通过 `tools/export_companion_motion.cjs` 导出原生尺寸。完整提示词、引用图和每个输出文件在 [VILLAGE_MOTION_ASSET_PROMPTS.json](VILLAGE_MOTION_ASSET_PROMPTS.json)。已有商店图标与角色原图未替换。

更新后可按 Ctrl+F5 刷新游戏。开发时的浏览器与独立数据库检查结果记录在 `progress.md`；正式数据库不用于写入式测试。

本轮验证：76 项 Node 回归、58 个 PHP／28 个 JS 与工具文件语法及六组 PHP 规则通过。独立数据库后端链覆盖旧战斗／剧情／复习／技能／商店／游客升级。实际 Chrome 验证商店 E 入口在未击败史莱姆时可用、六种购买与装备、真实动作帧变化、左右转身朝向、飞行高度、刷新与旧内部存档退出；另完成三个世界的真实外部胜利、五场内部胜利和三关打字。中英文七种尺寸与标准网页游戏客户端截图、状态已实际检查。
