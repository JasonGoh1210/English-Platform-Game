# 学习记录、历史错题与战斗暂停

## 使用方式

- 地图人物面板的书本数字现在表示「学过的不同题目数量」，读取当前角色保存的战斗作答记录。点书本或设置里的「学习与错题」进入学习页；战后总结也有同一入口。
- 学习页显示不同题目数、战斗答题次数、正确率、答错/超时次数。历史错题按最近作答排列，可分页查看自己的原答案、正确答案与中英解释。
- 每道错题可以「再练这题」。判断、找异词、句子排序均支持不限时再练；排序可以撤回词块、清空重排。服务器按照原来保存的题目判分，练习保留原来的战斗记录，奖励仍在冒险中获得。
- 进入学习页前会保存当前地图位置。战后进入学习页也会完成原有的进度保存和战斗退出；返回地图后继续同一个角色的冒险。
- 战斗中打开设置会暂停题目。关闭设置并确认恢复后继续原题；暂停期间刷新会重新打开设置。技能、药草、逃跑和连续答题继续使用原有规则。

## 数据与兼容

直接使用现有 `verified_battles` 和 `verified_answer_attempts`，无需数据库迁移。已保存的错题使用原题快照，题库内容更新不会替换旧答案。只开放本人已结束战斗的错题；进行中的战斗不会通过复习入口提前揭示答案。统计包含已保存的作答，旧版本没有记录的题目无法补算。

暂停时间保存在原有战斗 JSON。`PAUSE` / `RESUME` 采用现有动作凭证、事务和账号归属校验；重试使用同一请求凭证。暂停中不能提交答案、使用技能或购买药草。恢复时从服务器作答时间中扣除暂停时长，不会重置已用时间；药草原有的购买暂停继续兼容。

本轮保留四世界坐标、玩家/NPC/怪物素材、原有剧情和洞穴、题库与奖励数值。无新增 PNG、音频或 SQL 文件，无玩家重置。Google 登录已有功能仍需用户自己的 Client ID；配置步骤见 [Google 登录说明](GOOGLE_SIGNIN_AND_CHARACTERS.md)。
