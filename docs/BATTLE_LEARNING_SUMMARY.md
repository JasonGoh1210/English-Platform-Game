# 战后学习总结

胜利或失败后，原有结算窗口现在包含本场学习总结：题目数、答对、答错、超时与正确率。超时单独计数；正确率为答对数除以全部已判定题目数。全部答对时显示鼓励信息。

错题可展开，查看原题、单词选项、自己的答案、正确答案和解释。判断题保留 TRUE／FALSE，找异词显示选项，排句题显示原来提交的顺序和正确顺序。中文模式显示中英说明，English 模式显示英文；结算窗口内可直接切换语言。

题目仍然连续出现；学习总结只在战斗结束后读取。胜利保留返回地图；失败保留重新挑战，并增加返回地图。滚动长总结时，退出／重新挑战按钮保持可用。逃跑仍然直接返回地图。

## 记录与旧数据

- `api/battle_review.php` 是只读接口，服务器从当前登录角色获取所有权，只允许查看自己已经结束的战斗。未结束返回 409，其他角色的战斗返回 404。
- 使用已有 `verified_battles`、`verified_answer_attempts`。不新增表，不修改旧记录，不调用奖励接口。刷新、切换语言、分页和重复读取都不会增加 XP、金币、英语力量或作答次数。
- 每次返回最多 10 道错题；更多题目通过“查看更多错题”读取。统计一直是整场数值，分页不累加统计。
- 原题和正确答案来自当时保存的题目快照。10 道原来缺少解释的找异词／排句题已补上中英解释，题目、答案、时限、题池和奖励均不改变。
- 旧快照缺少解释时，只有题目 ID、题型、题目、提示、选项与正确答案全部匹配，才使用当前题库的解释。不会用新答案覆盖旧答案。
- 提交内容按文字显示，不能作为 HTML 执行。读取失败时显示重试按钮，原来的返回／重新挑战操作不受影响。

这是本场结算中的总结，尚未加入地图上的历史错题入口或独立复习答题奖励。返回地图或开始新战斗后，已有 MySQL 作答记录仍保留；当前窗口只显示当前战斗。刷新尚未离开的结算页可重新读取同一场记录。
