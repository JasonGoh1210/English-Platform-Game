# Pixel particle effects

The village shop now offers six permanent cosmetics: Sakura Petals (30 Coins), Golden Starlight (40), Forest Fireflies (45), Frost Footsteps (50), Ember Sparks (55) and Rainbow Dust (70). Buy with earned Coins, then equip the effect in the shop or backpack. One effect can be worn alongside any companion. The default No particle effect option turns it off for free. Effects appear during map exploration, including interiors; they do not alter combat, answers, progression or rewards.

Animated 128px Canvas previews use the same six patterns as exploration. Pixel blocks use integer coordinates, no blur filters or external assets. Emitters are capped at 48 particles and reset on scene changes/teleports/unequipping. Offscreen shop previews skip painting; hidden pages pause preview updates. Reduced-motion preference hides the map trail and presents static shop previews.

Ownership and the equipped effect are stored in the existing trusted shop transaction ledger, independently of companion selection. Old inventories default to `ownedEffects: ['none']` and `equippedEffect: 'none'`. Prices and ownership are checked on the server; player locking, request replay, CSRF and transactional rollback remain in force. Client map saves cannot grant effects. No SQL migration, asset install or account reset is needed.
